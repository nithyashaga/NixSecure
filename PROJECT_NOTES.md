# NixSecure project notes

## What the demo proves
1. A real React frontend with a 3D security core.
2. A FastAPI backend with SQLite persistence.
3. Local account creation/login and guest mode.
4. Stored synthetic enterprise device security profiles.
5. Manual ML risk prediction using a saved Random Forest pipeline.
6. Explainable contributing indicators and rule-based recommendations.
7. Persistent risk history.
8. Model benchmark metrics and confusion matrix.

## What it does not claim
It does not monitor real enterprise networks, detect live attacks, or replace SIEM/EDR systems. The project uses synthetic/demo data.
