# NixSecure — Predict. Prioritize. Protect.

NixSecure is a presentation-ready full-stack cybersecurity risk prediction prototype. It uses stored, synthetic security indicators for enterprise devices and runs a Random Forest model on demand to produce an explainable LOW/MEDIUM/HIGH risk assessment and recommended actions.

## Important scope
This project intentionally does **not** perform live monitoring, packet capture, IP/port scanning, exploitation, endpoint agents, or unauthorized network activity. It is an educational prototype using synthetic/demo data.

## Stack
- Frontend: React + TypeScript + Vite + Three.js/React Three Fiber + Recharts + Framer Motion
- Backend: FastAPI + SQLAlchemy + SQLite
- ML: Scikit-learn + Random Forest

## Run
### Backend
```powershell
cd backend
python -m pip install -r requirements.txt
python seed.py
python -m uvicorn main:app --reload --port 8000
```

### Frontend
Open another terminal:
```powershell
cd frontend
npm install
npm run dev
```
Open http://localhost:5173

## ML note
`models/metrics.json` contains evaluation results for the synthetic dataset generated by `backend/ml/train_model.py`. These numbers are not claims of real-world enterprise performance.

## Project structure
- `frontend/` React web application
- `backend/` FastAPI API, SQLite database and ML service
- `data/` synthetic dataset + SQLite database after initialization
- `models/` trained Random Forest and evaluation metrics
- `assets/` original NixSecure logo
